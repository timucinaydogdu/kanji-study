📖 N5-001 — N5 Gramer Dersi
Gizle ▲
N5 · 001 · Temel Yüklem
だ・です
da / desu
…dir, …dır (temel yüklem)
Japoncanın en temel yüklemi — to be (am, is, are)
Yapı
İsim / な-Sıfat + です / だ → …dir (geniş, olumlu)
İsim / な-Sıfat + じゃない / ではない → …değil (olumsuz)
İsim / な-Sıfat + でした / だった → …dı (geçmiş, olumlu)
İsim / な-Sıfat + じゃなかった → …değildi (geçmiş, olumsuz)

Dikkat Noktaları
💡Yeni öğrenenler için です her zaman güvenlidir. Sade konuşmada だ kullanılır.
⚠️い-sıfatlar (たかい、さむい vb.) + だ KULLANILMAZ. たかいだ → さむいです ✅
🗣️Soru için: resmi → cümle + か; sade → intonasyon yükselir.
