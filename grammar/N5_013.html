📖 Ders — N5-013
Gizle ▲

の üç ana işlevi vardır: 1) İyelik (benim kitabım), 2) İsim bağlantısı (Japonca öğretmeni), 3) Fiili isme çevirme.

Yapı
İyelik++ の→A'nın B'si (bağlantı/iyelik)
Nominalizasyon++ V + の + が/を→…mak (fiilden isim)
Açıklama+ 〜のです / 〜んです→aslında…; çünkü (açıklama)
Örnek Cümleler
1
これ は わたし の ほん です。
kore wa watashi no hon desu.
Bu benim kitabım.
わたし = benほん = kitap
2
にほんご の せんせい は だれ ですか。
nihongo no sensei wa dare desu ka?
Japonca öğretmeni kim?
にほんご = Japoncaせんせい = öğretmen
3
おんがく を きく の が すき です。
ongaku wo kiku no ga suki desu.
Müzik dinlemeyi seviyorum.
おんがく = müzikきく = dinlemekすき = sevmek
4
どうして おくれた の ですか？
dōshite okureta no desu ka?
Neden geç kaldınız?
どうして = nedenおくれた = geç kaldı
Dikkat Noktaları
💡
の nominalizasyon: 「V + の + が/を」→ fiili isim gibi kullanır: たべるのがすき ✅
⚠️
んです / のです açıklama: "aslında…" veya "…çünkü" anlamında. 「どうしたんですか」= Ne oldu? (açıklama iste)
